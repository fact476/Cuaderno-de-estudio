Datos de mercado con Python y pandas

Antes de cualquier estrategia o modelo, hay que tener los datos en orden. En Python la herramienta estándar es pandas: guarda los precios en una tabla con fechas y te deja calcular columnas nuevas en una línea.

1. Una tabla con fechas: el DataFrame

Cada fila es un día y cada columna un dato: apertura, máximo, mínimo, cierre y volumen. La fecha es el índice de la tabla, lo que permite pedir «el cierre del 3 de marzo» o «todo marzo».

import pandas as pd

df = pd.read_csv("precios.csv", parse_dates=["fecha"], index_col="fecha")
df.head()

Tener la fecha como índice es lo que hace a pandas tan útil para series de tiempo: alinea, agrupa por semana y desplaza datos sin que tengas que contar filas.

4. Un cuaderno completo, en pocas líneas

import pandas as pd

df = pd.read_csv("precios.csv", parse_dates=["fecha"], index_col="fecha")
df = df.sort_index().dropna()

df["retorno"] = df["close"].pct_change()
df["media_20"] = df["close"].rolling(20).mean()
df["sobre_media"] = df["close"] > df["media_20"]

semanal = df["close"].resample("W").last()
print(df.tail())
print("Días sobre la media:", df["sobre_media"].mean())
