Conectarse a la API de un bróker

La API del bróker es la puerta por la que tu programa hace lo mismo que tú haces con la aplicación: ver precios, enviar órdenes y revisar posiciones. La diferencia es que el programa no se cansa, pero tampoco tiene sentido común: hay que darle reglas para cuando algo sale mal.

1. Pedir y escuchar

Piensa en un mesero. Tu programa le hace pedidos (solicitudes) y el bróker responde. Pero algunas cosas llegan sin que las pidas en ese momento: un precio nuevo, una orden que se ejecutó, una desconexión. Esas son los eventos, y tu programa tiene que estar escuchándolos siempre.

Autenticación

Demuestras quién eres con una llave o una sesión iniciada. Nunca va escrita en el código.

Solicitudes

Pides datos, envías o cancelas órdenes, consultas posiciones.

Eventos

Precios, cambios de estado de órdenes, ejecuciones, errores. Llegan cuando ocurren.

Límites

El bróker limita cuántas solicitudes por segundo aceptas enviar. Si te pasas, te frena o te desconecta.

3. Un esqueleto de programa

  
Este esqueleto no usa una librería real: muestra la estructura que casi todas comparten. Las credenciales salen de variables de entorno y cada orden pasa por un control de riesgo antes de salir.


import os, logging
logging.basicConfig(filename="robot.log", level=logging.INFO)

CUENTA = os.environ["BROKER_CUENTA"]       # nunca escrita en el código
MODO = os.environ.get("BROKER_MODO", "papel")  # papel o real

MAX_CONTRATOS = 2
MAX_PERDIDA_DIA = 300                      # en dólares

def control_de_riesgo(orden, estado):
    if orden.cantidad > MAX_CONTRATOS:
        return "cantidad mayor al máximo"
    if estado.perdida_del_dia >= MAX_PERDIDA_DIA:
        return "límite de pérdida diaria alcanzado"
    return None

def al_conectar(api):
    estado.ordenes = api.ordenes_abiertas()   # reconciliar
    estado.posicion = api.posiciones()
    logging.info("Conectado en modo %s", MODO)

def al_ejecutarse(ejecucion):
    logging.info("Ejecutada %s", ejecucion)
    estado.actualizar(ejecucion)

def enviar(api, orden):
    motivo = control_de_riesgo(orden, estado)
    if motivo:
        logging.warning("Orden bloqueada: %s", motivo)
        return
